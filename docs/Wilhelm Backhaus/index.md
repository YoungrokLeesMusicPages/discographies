## Format

The original HTML is a visual FrontPage document, not a data table. The discography appears as composer headings, nested lists, blockquotes, line breaks, inline links, and occasional image markers such as "new" badges.

This Markdown distillation uses one table row per recording event. That is the most stable machine-readable grain because a single work may have several recordings, and each recording may have separate 78s, LP, and CD release information. Repeated release lists remain in a single cell, separated with the punctuation from the source, so they can be split later without losing the original catalog wording.

Columns:

- `composer`: composer heading from the source page.
- `work`: normalized work title; nested source groupings are joined with an em dash.
- `recording_no`: the source's numbered recording variant under the work.
- `recording_details`: date, venue, live/studio status, and other event-level description before release labels.
- `performers`: collaborators listed in source `* with ...` lines.
- `producer_engineer`: source `Producer/Engineer` field where present.
- `78s_info`, `lp`, `cd`: release information by source media label.
- `transfer`: source transfer/remastering credit, usually from `Transferring from 78s`.
- `other_formats`: any labelled format that did not fit the standard media columns.
- `notes`: source notes attached to the recording.

## Original Introductory Notes

- The source describes the discography as imperfect because 78s-era recordings and Decca monaural Beethoven sonatas are incompletely documented.
- Additional information was explicitly welcomed, including recording data not on the page, broadcast recordings, and rare CDs.
- Album numbers were linked to jacket images where available.
- Recently available CDs were prioritized.
- Items from labels such as Iron Needle and Enterprise were mostly excluded, with the original page linking to Music & Arts' "Hall of Shame" as the reason.
- Serial numbers and abbreviations were delegated to the original site's label-notes page.
- Special thanks were given to Jui-Yuan Yen and Philip Stuart, especially for Stuart's Decca recordings catalog.

- General resources named in the source include Youngrok Lee's own records, All Classical Guide, Amazon USA/Japan, Japanese HMV, Japanese Tower Records, record-company catalogs, ArkivMusic, Philip Stuart's Decca catalog, and the HMV DB database.
- Special contribution notes credit Chiu Chi Lin's Backhaus discography, John Hunt's arrangement, Jui-Yuan Yen's Toshiba-EMI/Shinseido and Italian-release data, and many named collectors or discographers.
- The personal-contribution list includes Ferenc Fricsay discography material, Decca LP information, Classical Vinyl Artwork, Mozart Concerto No.27 data, HIMAHITO Kitagawa's Decca LXT catalog, Japanese Backhaus complete Decca correction data, Brahms Concerto No.2 material, Knappertsbusch/Karajan-related references, Testament release notification, and Naxos 78s release information.
- Final notes say that Decca's limited edition "The Complete Backhaus" 46-LP set is excluded for lack of data; that Philips/Decca online dates for Philips 456 718-2 are wrong; and that some Decca-set recording information was not accepted as first-priority evidence because of source disagreements.
